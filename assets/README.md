# Assets

Drop the hero artwork here as **`coach.png`** (transparent background, shown full-size with a purple glow)
or **`coach.jpg`** (photo, shown circle-cropped). PNG is checked first.

If `assets/coach.jpg` exists, the sign-in screen shows it (circle-cropped with a purple glow)
instead of the built-in vector coach. Delete the file to fall back to the vector version.
